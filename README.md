# Leave Management System

## Project Overview

The ServiceNow Leave Management System automates the employee leave management process. Employees can apply for leave, view their leave balances, track application statuses, and check their leave history. Managers can review, approve, or reject leave requests.

The application provides a centralized platform for managing leave-related activities with role-based access and workflow automation.

## Objectives

- Simplify the employee leave application process.
- Automate manager approval workflows.
- Maintain employee leave balances.
- Provide real-time leave request status tracking.
- Send notifications for important leave activities.
- Display leave statistics through an analytics dashboard.
- Improve transparency and reduce manual work.

## Application Workflow

1. Employee logs into the application.
2. Employee views available leave balances.
3. Employee submits a leave request.
4. The system validates the request.
5. The manager receives the request for approval.
6. The manager approves or rejects the request.
7. The system updates the request status and relevant leave balance.
8. Notifications inform the employee about the outcome.

## User Roles

- **Employee:** Applies for leave and tracks personal requests.
- **Manager:** Reviews and processes team leave requests.
- **Admin:** Manages application data and administrative operations.
